# Detour на Linux-сервере (VPS)

Свой VPN-сервер на арендованном VPS: AmneziaWG, VLESS-Reality, по желанию
VLESS поверх TLS, WebSocket и xhttp. Клиенты (телефон, ноутбук) подключаются
к серверу и выходят в интернет либо прямо с его адреса, либо дальше через
профили и цепочки Detour — с теми же правилами, что на роутере: списки
сайтов, «Всё через VPN», отдельные маршруты, zapret, торренты.

Отдельного пакета под Linux нет: Detour живёт в Docker-контейнере с настоящим
OpenWrt 25.12, туда ставится тот же `detour_*_noarch.apk`, что и на роутер.
Всё делает один скрипт `install.sh`.

## Что нужно

- VPS с Linux (проверено на Ubuntu 24.04; подойдёт Debian и любой другой
  дистрибутив, где есть Docker), x86_64 или arm64;
- доступ root по SSH;
- белый IP-адрес (у обычного VPS он есть) или домен, который на него указывает.

## Установка за пять шагов

### 1. Зайти на сервер

```sh
ssh root@<IP сервера>
```

На Windows эта команда работает в PowerShell и в «Терминале» — OpenSSH там
встроен.

### 2. Поставить Docker и git

Если Docker уже стоит (`docker version` отвечает), шаг пропустите.

```sh
apt-get update && apt-get install -y git curl
curl -fsSL https://get.docker.com | sh
```

Второй строкой ставится официальный Docker с сайта docker.com. На других
дистрибутивах (не Debian/Ubuntu) поставьте `git` своим менеджером пакетов —
скрипт Docker поддерживает и их.

### 3. Скачать Detour и запустить установку

```sh
git clone https://github.com/varyen/detour /root/detour
sh /root/detour/linux/install.sh
```

Скрипт загрузит в ядро модули перехвата трафика, соберёт образ (первый раз —
5–10 минут) и запустит контейнер `detour`. В конце он напечатает адрес панели и
порты:

```
Detour запущен.

  Панель:   http://127.0.0.1:8080/detour/
            (доступна только с сервера; со своего компьютера:
             ssh -L 8080:127.0.0.1:8080 root@<IP сервера>
             и откройте http://127.0.0.1:8080/detour/)
  ...
```

Без параметров сервер слушает AmneziaWG на `51820/udp`, VLESS-Reality на
`443/tcp` (если 443 занят — на `8443`), подписки клиентов — на `2096/tcp`.
Свои порты и дополнительные входы — в таблице [«Параметры»](#параметры).

### 4. Открыть порты

Если у провайдера VPS есть файрвол в личном кабинете («Security groups»,
«Firewall»), откройте в нём входящие:

| Порт | Зачем |
|---|---|
| `51820/udp` | AmneziaWG |
| `443/tcp` | VLESS-Reality |
| `2096/tcp` | ссылки подписки клиентов |
| `80/tcp` | выпуск сертификата Let's Encrypt (если будете привязывать домен) |
| `8443/tcp` | панель по HTTPS после выпуска сертификата |

`ufw` и `firewalld` на самом сервере трогать не нужно: опубликованные порты
Docker открывает в обход них.

### 5. Зайти в панель и включить сервер

Панель по умолчанию закрыта от интернета. Со **своего компьютера** (не на
сервере) пробросьте её через SSH и не закрывайте это окно:

```sh
ssh -L 8080:127.0.0.1:8080 root@<IP сервера>
```

Откройте в браузере `http://127.0.0.1:8080/detour/`:

1. Придумайте логин и пароль — панель спросит их при первом входе.
2. «Сервисы» → «Свой VPN-сервер» → включить. Порты уже совпадают с
   опубликованными, менять их не нужно.
3. «Добавить клиента» — на каждого человека или устройство свой.
4. В карточке клиента — QR-код, ссылка `vless://`, конфиг AmneziaWG и ссылка
   подписки (все протоколы клиента одной ссылкой, обновляются сами).
   Подходят Detour Home Auto, приложение Detour, AmneziaVPN, v2rayNG, Hiddify,
   Happ, Streisand.

Профиль VPN в панели добавлять **не обязательно**: без него клиенты выходят в
интернет прямо с адреса VPS. Профиль или подписка нужны, если выход должен
быть в другом месте — тогда включите «Всё через VPN» или нужный режим
маршрутизации, как на роутере.

## Параметры

Все параметры — у `install.sh`; чтобы поменять их, запустите скрипт ещё раз с
новыми значениями (настройки и клиенты сохранятся).

| Параметр | Что делает |
|---|---|
| `--port 51820` | UDP-порт AmneziaWG |
| `--vless-port 443` | TCP-порт VLESS-Reality; по умолчанию 443, если занят — 8443 |
| `--endpoint <IP или домен>` | адрес в конфигах клиентов; по умолчанию — внешний IP сервера |
| `--panel-port 8080` | порт панели на хосте |
| `--panel-public` | открыть панель в интернет (по умолчанию — только 127.0.0.1). Задайте пароль **до** этого: без учётки панель достанется первому, кто её откроет |
| `--sub-port 2096` | порт подписок клиентов; `0` — без подписок |
| `--sub-local` | подписки только на 127.0.0.1 — под свой nginx с TLS (его адрес задаётся в панели) |
| `--tls-port 4430` | вход VLESS поверх обычного TLS на настоящем сертификате — там, где сеть ломает Reality |
| `--https-port 8443` | порт панели по HTTPS после выпуска сертификата; `0` — не публиковать |
| `--no-acme` | не пробрасывать 80-й порт для Let's Encrypt |
| `--acme-port 80` | другой порт хоста для проверок Let's Encrypt (если 80-й держит свой веб-сервер) |
| `--ws-port 10080` | вход VLESS через WebSocket на 127.0.0.1 — под свой nginx с сайтом и сертификатом |
| `--xhttp-port 10081` | то же для VLESS xhttp (nginx нужен с `http2`) |
| `--xhttp-reality` | вход xhttp без nginx: `--xhttp-port` открывается наружу, маскировка Reality — проходит мобильные сети |
| `--name detour` | имя контейнера и томов (для второй копии) |
| `--uninstall` | удалить контейнер; тома с настройками остаются |

`sh install.sh --help` печатает подробную справку.

### Свой домен и HTTPS

1. Заведите A-запись домена на IP сервера.
2. Переустановите с этим доменом: `sh /root/detour/linux/install.sh --endpoint vpn.example.com`
   (и `--tls-port 4430`, если нужен вход VLESS+TLS).
3. В панели — «Сервисы» → «Свой домен и защищённое соединение» → выпустить сертификат.
   После этого панель открывается на `https://vpn.example.com:8443/detour/`,
   подписки переходят на HTTPS, вход VLESS+TLS берёт тот же сертификат.

Если на 80-м порту уже работает свой веб-сервер, сертификат через панель не
выпустится — либо отдайте `/.well-known/acme-challenge/` на `--acme-port`, либо
выпустите сертификат на хосте и положите его в том контейнера
(`detour-detour`, файлы `server/tls/fullchain.pem` и `privkey.pem`).

### WebSocket и xhttp за nginx

Для сетей, где режут и Reality, и TLS на нестандартном порту: VLESS прячется
внутрь обычного HTTPS-сайта на вашем nginx.

1. Установите с `--ws-port 10080 --xhttp-port 10081` — входы откроются
   только на 127.0.0.1.
2. В панели («Свой VPN-сервер») включите «VLESS + WebSocket» и «VLESS +
   xhttp», в «Адрес реверс-прокси для WebSocket» впишите адрес сайта
   (`vpn.example.com:443`). «Путь WebSocket» и «Путь xhttp» панель создаёт
   сама — это секреты, по которым nginx отличает туннель от сайта.
3. В nginx-сайт с сертификатом добавьте `http2` в `listen` и проксируйте эти
   пути на порты входов (WebSocket — точный путь `=`, xhttp — префиксом):
   ```nginx
   listen 443 ssl http2;

   location = /ws-путь {
       proxy_pass http://127.0.0.1:10080;
       proxy_http_version 1.1;
       proxy_set_header Upgrade $http_upgrade;
       proxy_set_header Connection "upgrade";
       proxy_set_header Host $host;
       proxy_buffering off;
       proxy_read_timeout 1h;
       proxy_send_timeout 1h;
   }
   location /xhttp-путь {
       proxy_pass http://127.0.0.1:10081;
       proxy_http_version 1.1;
       proxy_set_header Host $host;
       proxy_request_buffering off;
       proxy_buffering off;
       proxy_read_timeout 1h;
       proxy_send_timeout 1h;
       client_max_body_size 0;
   }
   ```
4. `nginx -t && systemctl reload nginx`. Ссылки и подписки клиентов уже
   указывают на nginx — клиентам достаточно обновить подписку.

## Обновление

- **Панель** — изнутри, как на роутере: кнопка «Обновить» в шапке.
- **Образ** (новый OpenWrt, AmneziaWG, sing-box) — обновите исходники и
  запустите скрипт с теми же параметрами:
  ```sh
  cd /root/detour && git pull && sh linux/install.sh <те же параметры>
  ```
  Контейнер пересоздаётся, настройки и клиенты остаются в томах
  `detour-detour`, `detour-singbox`, `detour-config`, `detour-zapret`.

## Удаление

```sh
sh /root/detour/linux/install.sh --uninstall
docker volume rm detour-detour detour-singbox detour-config detour-zapret  # вместе с настройками
```

## Если что-то не так

- `docker ps` — контейнер `detour` должен быть `Up`.
- `docker logs detour` — журнал запуска контейнера.
- Журналы самого Detour — в панели, «Журнал».
- Клиент не подключается — проверьте порт в файрволе провайдера VPS (шаг 4)
  и попробуйте другой вход: из мобильных сетей в России на части адресов не
  проходят Reality или TLS, тогда помогает WebSocket за nginx.

## Как это устроено

Ядро у контейнера общее с хостом, поэтому:

- модули netfilter (`ip_set`, `xt_TPROXY`, `xt_REDIRECT`…) грузит `install.sh`
  на хосте и прописывает в `/etc/modules-load.d/detour.conf`;
- AmneziaWG работает в userspace (`amneziawg-go`): модуля `amneziawg` в ядрах
  дистрибутивов нет, образ собирает его и утилиту `awg` из исходников Amnezia;
- вход VLESS-Reality — отдельный sing-box в своём сетевом пространстве внутри
  контейнера.

Файрвол Detour (fw4, iptables, ipset) работает в сетевом пространстве
контейнера и файрвол хоста не трогает. `--privileged` обязателен: OpenWrt
внутри управляет своими интерфейсами и файрволом. Учётка панели и стратегия
zapret лежат вне томов и раз в минуту копируются в `/etc/detour/.box`.

Userspace AmneziaWG медленнее ядерного; для пары десятков клиентов на VPS
этого хватает.
