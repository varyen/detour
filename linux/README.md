# Detour на обычном Linux-сервере

VPN-сервер AmneziaWG и VLESS-Reality на своём VPS. Клиенты (телефон, ноутбук) подключаются к
серверу, а наружу выходят через профили и цепочки Detour — с теми же
правилами, что на роутере: списки сайтов, «Всё через VPN», отдельные
маршруты, zapret, торренты через разрешённый профиль.

## Как это устроено

Detour написан под OpenWrt, поэтому на сервере он живёт в контейнере с
настоящим OpenWrt 25.12. Ставится тот же пакет `detour_*_noarch.apk`, что и на
роутер, весь код общий. Файрвол Detour (fw4, iptables, ipset) работает в
сетевом пространстве контейнера и файрвол хоста не трогает.

Ядро у контейнера общее с хостом, поэтому:

- модули netfilter (`ip_set`, `xt_TPROXY`, `xt_REDIRECT`…) грузит `install.sh`
  на хосте и прописывает в `/etc/modules-load.d/detour.conf`;
- AmneziaWG работает в userspace (`amneziawg-go`): модуля `amneziawg` в ядрах
  дистрибутивов нет. Образ собирает его и утилиту `awg` из исходников Amnezia;
- вход VLESS-Reality — отдельный sing-box в своём сетевом пространстве внутри
  контейнера (нужен `ip-full`, он есть в образе).

## Установка

Нужны root и Docker, архитектура x86_64 или arm64.

```sh
git clone https://github.com/varyen/detour
sh detour/linux/install.sh
```

Параметры:

| | |
|---|---|
| `--port 51820` | UDP-порт AmneziaWG (публикуется на хосте) |
| `--vless-port 443` | TCP-порт VLESS-Reality; по умолчанию 443, если занят — 8443 |
| `--endpoint <IP или домен>` | адрес для конфигов клиентов; по умолчанию — внешний IP |
| `--panel-port 8080` | порт панели на хосте |
| `--panel-public` | открыть панель на все адреса (по умолчанию только 127.0.0.1) |
| `--uninstall` | удалить контейнер (тома с настройками остаются) |

Панель по умолчанию доступна только с самого сервера. Со своего компьютера:

```sh
ssh -L 8080:127.0.0.1:8080 root@<сервер>
```

и откройте `http://127.0.0.1:8080/detour/`. При первом входе панель предложит
задать логин и пароль. Дальше: добавить профиль или подписку, выбрать
«Всё через VPN» (или нужный режим маршрутизации) и в «Сервисы → Свой
VPN-сервер» включить сервер, нужные входы и завести клиентов. Порты сервера
уже совпадают с опубликованными. Контейнер, установленный до версии 2.7.0,
публикует только UDP — для VLESS запустите `install.sh` ещё раз.

## Обновление

Панель обновляется изнутри, как на роутере («Обновить» в шапке). Чтобы
пересобрать образ (новый OpenWrt, новый AmneziaWG), запустите `install.sh`
ещё раз: контейнер пересоздаётся, настройки остаются в томах `detour-detour`,
`detour-singbox`, `detour-config`, `detour-zapret`. Учётка панели и
стратегия zapret лежат вне томов и копируются в `/etc/detour/.box` раз в
минуту.

## Ограничения

- `--privileged` обязателен: OpenWrt внутри управляет своими интерфейсами и
  файрволом. Сеть при этом у контейнера своя.
- Userspace AmneziaWG медленнее ядерного; для пары-тройки клиентов на VPS
  этого хватает.
