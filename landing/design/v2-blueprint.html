Обход блокировок — на роутере, для всей сети

Detour — веб-панель, которая объединяет два движка: прозрачный прокси sing-box и DPI-обход zapret. Правила задаются мышкой, трафик разводится на роутере, устройствам ничего ставить не нужно.

Один раз на роутере — вместо клиента на каждом устройстве

VPN-клиент на ноутбуке решает задачу только для ноутбука. Detour переносит обход на уровень домашней сети: трафик разводится прозрачно, устройствам не нужно ничего знать и ставить.

Для всей сети сразу

Телевизор, консоль, колонка, рабочий ноутбук гостя — трафик заворачивается на роутере, клиент не нужен нигде.

Только то, что нужно

В туннель уходят выбранные домены и подсети, остальное — напрямую. Или наоборот: всё, кроме списка исключений.

Два движка вместо одного

sing-box — когда нужен зарубежный выход. zapret — когда сайт душит DPI и хватает трюков с пакетами, без сервера.

Ваша инфраструктура

Никаких чужих аккаунтов и телеметрии. Профили и ключи хранятся на роутере, панель закрыта паролем с защитой от перебора.

Обновления подписаны

Пакет .ipk с usign-подписью; панель обновляет себя и бинарники из собственного opkg-фида — с откатом.

Ничего лишнего на роутере

Бэкенд — BusyBox ash и немного Lua: ни Python, ни Node, ни PHP. Пакет панели — около 130 КБ.

DNS подсказывает, файрвол разводит трафик

Когда устройство резолвит домен из списка, dnsmasq кладёт адрес в набор ipset. Правила nat PREROUTING решают, куда отправить соединение, не разбирая пакеты. UDP при необходимости заворачивается через TPROXY — играм, голосу и QUIC. Перезапуск сервиса не открывает прямой путь: размеченный адрес скорее не работает, чем идёт мимо VPN.

Что умеет панель

Все кадры сняты с живого роутера; данные обезличены. Оранжевым пунктиром помечены места под короткие ролики.

Профили и подписки

Профиль добавляется вставкой ссылки vless://, trojan://, vmess://, ss://, socks5:// либо руками по полям; WireGuard — своя вкладка. Подписка провайдера обновляется по расписанию и сама раскладывает серверы по группе.

ролик: вставка ссылки → профиль

Проверка, скорость и автопереключение

Пинг говорит только о живом входном узле. Панель поднимает временный sing-box и ходит через него на реальные адреса, замеряя скорость. Мёртвый сервер виден до переключения; если активный отвалится — панель подберёт живой и пришлёт уведомление.

ролик: «Сменить VPN» → список по скорости

Маршруты по сайтам

Разные сайты — через разные выходы одновременно. Маршрут описывает, какой профиль или цепочка забирает указанные домены, поддомены, адреса и подсети.

Режимы туннеля и списки

«Только выбранные сайты» — в туннель уходит список. «Всё, кроме исключений» — всё, что не попало в белый список. Списки принимают домены, поддомены, адреса и подсети с комментариями.

Цепочки и Cloudflare WARP

Клиент → VPN 1 → VPN 2 → интернет. Отдельный сценарий — бесплатный WARP последним хопом: выходной адрес перестаёт выглядеть адресом дата-центра.

Пустить в дом: публикация сервисов наружу

Обратная задача — зайти домой снаружи. Панель выпускает сертификат Let's Encrypt для вашего домена и публикует сервис: по имени, по порту или пробросом.

Главная под себя и поиск по всему

«Обзор» собирается из карточек: набор, порядок и ширина — перетаскиванием. График трафика — направления или скорость за час, сутки, неделю, месяц.

ролик: перетаскивание карточек

Диагностика и обновления

Журнал событий, логи служб, итоговый конфиг и правила файрвола — в одном месте. Обновление панели и бинарников — из подписанного фида, с откатом.

Та же панель, а не урезанная версия

Панель — PWA: ставится на домашний экран и открывается как приложение. С телефона доступно всё то же самое. Когда активный VPN отваливается, роутер присылает Web Push.

Две прошивки, один интерфейс

OpenWrt / GL.iNet

Основная платформа. Референс — GL.iNet GL-BE9300 (Flint 3) на OpenWrt 23.05; проверялось на GL-MT6000 (Flint 2).

Keenetic / Entware

Нет nftables и NFQUEUE — часть механик сделана иначе, zapret2 недоступен физически. Собирается из того же исходника.

Один пакет, дальше всё само

Скачать пакет

Из GitHub Releases: detour_X.Y.Z_all.ipk для OpenWrt / GL.iNet либо detour-keenetic_X.Y.Z_all.ipk для Keenetic. Рядом .ipk.sig.

Установить

scp на роутер и opkg install. Панель сама пропишет фид и подтянет sing-box и tpws-zapret.

Открыть панель

Через полминуты — http://192.168.8.1:8080/detour/.

# OpenWrt / GL.iNet
scp detour_X.Y.Z_all.ipk root@192.168.8.1:/tmp/
ssh root@192.168.8.1 'opkg install /tmp/detour_X.Y.Z_all.ipk'

# Keenetic / Entware
opkg install /tmp/detour-keenetic_X.Y.Z_all.ipk
