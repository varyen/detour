Обход блокировок живёт на роутере, а не на каждом устройстве

Detour — панель для роутера, которая объединяет два движка: прозрачный прокси sing-box (VLESS, Trojan, VMess, WireGuard, Shadowsocks, Hysteria2, TUIC) и DPI-обход zapret без всякого сервера. Настраивается мышкой и работает сразу для всей домашней сети — включая телевизор, приставку и колонку.

Один раз на роутере — вместо клиента на каждом устройстве

VPN-клиент на ноутбуке решает задачу только для ноутбука. Detour переносит обход на уровень домашней сети: трафик разводится прозрачно, устройствам не нужно ничего знать и ставить.

Для всей сети сразу

Телевизор, консоль, колонка, рабочий ноутбук гостя — трафик заворачивается на роутере, клиент не нужен нигде.

Только то, что нужно

В туннель уходят выбранные домены и подсети, остальное — напрямую и на полной скорости. Или наоборот: всё, кроме списка исключений.

Два движка вместо одного

sing-box — когда нужен зарубежный выход. zapret — когда сайт душит DPI и хватает трюков с пакетами, без всякого сервера.

Ваша инфраструктура

Никаких чужих аккаунтов и телеметрии. Профили и ключи хранятся на роутере, панель закрыта логином и паролем с защитой от перебора.

Обновления подписаны

Панель ставится пакетом .ipk с usign-подписью, умеет обновлять себя и бинарники из собственного opkg-фида — с откатом на предыдущую версию.

Ничего лишнего на роутере

Бэкенд — чистый BusyBox ash и немного Lua: ни Python, ни Node, ни PHP. Пакет панели — около 130 КБ.

DNS подсказывает, файрвол разводит трафик

Когда устройство резолвит домен из списка, dnsmasq кладёт полученный адрес в набор ipset. Дальше правила nat PREROUTING решают, куда отправить соединение — не разбирая содержимое пакетов, поэтому накладных расходов почти нет.

UDP при необходимости заворачивается отдельно, через TPROXY — это нужно играм, голосовым чатам и QUIC. Обещание «размеченный адрес скорее не работает, чем идёт мимо VPN» держится и в поломанных состояниях: перезапуск сервиса не открывает прямой путь.

Что умеет панель

Все кадры сняты с живого роутера; данные на них обезличены. Пунктиром — места, где по плану встанут короткие ролики.

Профили и подписки

Профиль добавляется вставкой ссылки vless://, trojan://, vmess://, ss://, socks5:// либо руками по полям; для WireGuard — своя вкладка. Подписка провайдера обновляется по расписанию и сама раскладывает серверы по группе.

ролик · вставка ссылки → профиль появился

Проверка, скорость и автопереключение

Пинг говорит только о том, что жив входной узел. Панель проверяет профили по-настоящему: поднимает временный sing-box и ходит через него на реальные адреса, замеряя скорость загрузки. Мёртвый сервер виден до того, как вы на него переключитесь, а если активный отвалится — панель сама подберёт живой и пришлёт уведомление.

ролик · «Сменить VPN» → список по скорости

Маршруты по сайтам

Разные сайты — через разные выходы одновременно. Маршрут описывает, какой профиль (или целая цепочка) забирает указанные домены, поддомены, адреса и подсети.

Режимы туннеля и списки

«Только выбранные сайты» — в туннель уходит список. «Всё, кроме исключений» — в туннель уходит всё, что не попало в белый список. Списки принимают домены, поддомены, адреса и подсети — с комментариями.

Цепочки и Cloudflare WARP

Профили выстраиваются в цепочку: клиент → VPN 1 → VPN 2 → интернет. Отдельный сценарий — бесплатный WARP последним хопом: выходной адрес перестаёт выглядеть адресом дата-центра, и сервисы, которые отказывают хостингам, начинают работать.

Пустить в дом: публикация сервисов наружу

Обратная задача — не выйти из дома, а зайти в него. Панель выпускает сертификат Let's Encrypt для вашего домена и публикует нужный сервис наружу: по имени, по порту или простым пробросом.

Главная под себя и поиск по всему

«Обзор» собирается из карточек: набор, порядок и ширина — перетаскиванием, прямо на месте. График трафика показывает направления или скорость приёма и передачи за час, сутки, неделю или месяц.

ролик · перетаскивание карточек

Диагностика и обновления

Журнал событий, логи служб, итоговый конфиг и правила файрвола — в одном месте. Обновление панели и бинарников — из подписанного фида, с откатом.

Та же панель, а не урезанная версия

Панель — PWA: ставится на домашний экран и открывается как приложение. С телефона доступно всё то же самое, включая списки, маршруты и диагностику. А когда активный VPN отваливается, роутер присылает Web Push.

Две прошивки, один интерфейс

OpenWrt / GL.iNet

Основная платформа. Референсное устройство — GL.iNet GL-BE9300 (Flint 3) на OpenWrt 23.05; проверялось также на GL-MT6000 (Flint 2).

Keenetic / Entware

Там нет nftables и NFQUEUE, поэтому часть механик сделана иначе, а движок zapret2 недоступен физически. Собирается из того же исходника.

Один пакет, дальше всё само

Скачать пакет своей платформы

Из GitHub Releases: detour_X.Y.Z_all.ipk для OpenWrt / GL.iNet либо detour-keenetic_X.Y.Z_all.ipk для Keenetic. Рядом лежит .ipk.sig — подпись релиза.

Скопировать на роутер и установить

Одна команда scp и одна opkg install. Панель сама пропишет opkg-фид проекта и подтянет sing-box и tpws-zapret в фоне.

Открыть панель

Через полминуты — http://192.168.8.1:8080/detour/. Дальше всё мышкой.

# OpenWrt / GL.iNet
scp detour_X.Y.Z_all.ipk root@192.168.8.1:/tmp/
ssh root@192.168.8.1 'opkg install /tmp/detour_X.Y.Z_all.ipk'

# Keenetic / Entware
opkg install /tmp/detour-keenetic_X.Y.Z_all.ipk
