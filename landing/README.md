# landing/ — сайт detour.varyen.net

Одностраничный статичный лендинг про панель Detour. Без сборки и зависимостей:
один `index.html` со встроенным CSS, `favicon.svg` и картинки в `img/`.

Каталог `img/` **в репозитории не хранится**: на кадрах реальные имена
VPN-сервисов, серверные IP и домен панели (см. «Персональные данные» в
`CLAUDE.md`). Картинки живут только локально и на сервере — их заливает
`deploy.sh`. На чистой машине репозиторий даёт разметку и скрипты, а кадры
надо переснять или скопировать отдельно.

| Путь           | Что это                                                            |
| -------------- | ------------------------------------------------------------------ |
| `index.html`   | Вся страница: разметка + стили инлайном.                            |
| `favicon.svg`  | Иконка вкладки.                                                     |
| `img/*.webp`   | Скриншоты, которые отдаются сайтом (gitignored).                    |
| `img/og.png`   | Картинка для og:image, 1200×630 (gitignored).                       |
| `img/*.png`    | Те же кадры до сжатия — исходники для правок (gitignored, ≈10 МБ).  |
| `raw/*.png`    | Кадры прямо со съёмки, без изменений (gitignored).                  |
| `webp.sh`      | Пересборка `img/*.webp` из `img/*.png`.                             |
| `deploy.sh`    | Выкладка на сервер по SSH.                                          |

## Выкладка

```sh
./landing/deploy.sh
```

Отправляются только `index.html`, `favicon.svg` и `img/*.webp`. На сервере —
nginx-вхост `/etc/nginx/sites-available/detour.varyen.net.conf`, корень
`/var/www/varyen/detour.varyen.net`, сертификат Let's Encrypt через
certbot webroot (`/var/www/certbot`), продление — штатным таймером certbot.

## Скриншоты

Кадры снимаются Playwright'ом с живой панели (headless Chromium, вход по
логину панели) и складываются в `landing/raw/`. Оттуда попадают в `img/*.png`
и выкладываются как есть — чистка данных на кадрах делается **вручную**,
поверх `img/*.png`.

После правки или пересъёмки:

```sh
./landing/webp.sh          # все кадры; или ./landing/webp.sh 05 13
./landing/deploy.sh
```

`webp.sh` жмёт `img/*.png` → `img/*.webp` (ширина ≤ 1560 px, мобильный
кадр — 620 px, качество 0.86) тем же headless Chromium: cwebp, ImageMagick
и Pillow на рабочей машине нет. `img/og.png` (1200×630 для og:image)
собирается отдельно из `25-dark.png`.
