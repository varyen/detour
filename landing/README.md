# landing/ — сайт detour.varyen.net

Одностраничный статичный лендинг про панель Detour. Без сборки и зависимостей:
один `index.html` со встроенным CSS и JS, `favicon.svg`, кадры в `img/`, ролики в
`video/`, сгенерированные фоны в `gen/` и свои шрифты в `fonts/`.

Каталоги `img/`, `raw/`, `video/` и `raw-video/` **в репозитории не хранятся**: это
кадры и ролики с живого роутера, и хотя данные на них подставные, снимаются они с
настоящего устройства (см. «Персональные данные» в `CLAUDE.md`). Они живут локально
и на сервере — их заливает `deploy.sh`. На чистой машине репозиторий даёт разметку,
фоны, шрифты и всю оснастку съёмки; кадры и ролики надо переснять.

| Путь              | Что это                                                          |
| ----------------- | ---------------------------------------------------------------- |
| `index.html`      | Вся страница: разметка, стили и параллакс инлайном.               |
| `favicon.svg`     | Иконка вкладки.                                                   |
| `pack.cjs`        | `raw/*.png` → `img/*.webp` (обрезка, размер, сжатие).             |
| `pack-gen.cjs`    | `gen-src/*.jpg` (нейросеть) → `gen/*.webp` в трёх размерах.       |
| `og.html`         | Исходник картинки для соцсетей; рендерится в `img/og.png`.         |
| `deploy.sh`       | Выкладка на сервер по SSH.                                        |
| `shoot/`          | Съёмка кадров (`shots.cjs`) и роликов (`clips.cjs`) с обезличиванием (`verify.py` — проверка). |
| `fonts/`          | Commissioner и JetBrains Mono, только cyrillic+latin; `fetch.cjs` их скачивает. |
| `gen/*.webp`      | Фоны из нейросети, пережатые под веб (в git).                     |
| `gen-src/*.jpg`   | Сырьё нейросети по 2–3 МБ (gitignored, ссылки живут 7 суток).     |
| `design/`         | Три варианта дизайна и страница выбора между ними (черновики, на сайт не идут). |
| `raw/*.png`       | Кадры прямо со съёмки (gitignored).                               |
| `raw-video/*`     | Сырые записи Playwright и `screenrecord` (gitignored).            |
| `img/*.webp`      | То, что отдаётся сайтом (gitignored).                             |
| `video/*`         | Ролики mp4 + webm + постеры jpg (gitignored).                     |
| `img/og.png`      | Картинка для og:image, 1200×630 (gitignored).                     |

## Выкладка

```sh
./landing/deploy.sh
```

Отправляются `index.html`, `favicon.svg`, `img/*.webp`, `img/og.png`, `gen/*.webp`,
`fonts/` и `video/*`. Адреса кадров, роликов и фонов в `index.html` несут
`?v=<дата>`: имена файлов постоянные, при пересъёмке файл подменяется под тем же
адресом, и без версии посетитель месяц видит старый кадр — в том числе тот,
который убрали из-за личных данных. Пересняли — поменяйте `?v=`.
На сервере — nginx-вхост `/etc/nginx/sites-available/detour.varyen.net.conf`,
корень `/var/www/varyen/detour.varyen.net`, сертификат Let's Encrypt через
certbot webroot (`/var/www/certbot`), продление — штатным таймером certbot.

## Скриншоты: как они снимаются

Кадры снимаются с **живой панели**, но панель при этом видит не настоящие
данные, а подставные: между браузером и роутером стоит обезличивающий прокси.
Раньше чистка делалась руками поверх готовых PNG — этот способ не масштабируется
и легко пропускает утечку (адрес подписки, например, содержит base64, внутри
которого лежит почта владельца).

```
Chromium ──► vite dev (panel/) ──► shoot/proxy.py ──► роутер :8080
             отдаёт текущую          подменяет в ответах CGI имена,
             сборку панели           серверы, адреса и токены
```

Порядок:

```sh
cd landing/shoot
npm install                       # playwright-core (браузер берётся из кэша)

python3 capture.py                # выгрузить ответы CGI в dump/ (нужно для карты)
python3 anonmap.py                # построить map.json — что на что заменяем
python3 proxy.py &                # обезличивающий прокси на 127.0.0.1:8099

cd ../../panel && DETOUR_DEV_TARGET=http://127.0.0.1:8099 npm run dev &
cd ../landing/shoot && BASE=http://localhost:5199/detour/ node shots.cjs   # порт печатает vite
```

`shots.cjs` кладёт кадры в `landing/raw/`; `node shots.cjs profiles m-*` снимет
только совпадающие по имени. Дальше:

```sh
node landing/pack.cjs             # raw/*.png → img/*.webp
node landing/shoot/og.cjs         # og.html → img/og.png (1200×630)
./landing/deploy.sh
```

Порт vite — `5199` (см. `panel/vite.config.ts`). Из Git Bash на Windows прокси
запускать с `PYTHONUTF8=1`, иначе `print` со стрелкой падает на cp1251.

## Ролики

Четыре петли по 7–8 с, без плеера (`<video autoplay muted loop playsinline>`):
вставка ссылки → поля заполнились, «Сменить VPN» → список по скорости,
перетаскивание карточки главной, тап по профилю на телефоне. Ничего не
сохраняют: ссылка только разбирается кнопкой «Разобрать», раскладка главной
живёт в `localStorage` свежего контекста.

**Десктоп** пишет Playwright тем же стендом, что и кадры (`recordVideo`), курсор
дорисовывается поверх страницы; ffmpeg переводит в постоянные 30 fps, режет
точную длину и кладёт `mp4` + `webm` + постер `jpg` в `video/`:

```sh
cd landing/shoot && node clips.cjs            # или node clips.cjs paste-link
```

**Телефон** — штатный `screenrecord` на Pixel по USB, vite при этом слушает LAN
(`npx vite --host 0.0.0.0`), Chrome на телефоне открывает
`http://<ip-машины>:5199/detour/`, прокси подставляет сессию сам. Из Git Bash
нужен `MSYS_NO_PATHCONV=1`, иначе `/sdcard/…` превращается в путь Git. Порядок:
`settings put system show_touches 1` → `screenrecord --time-limit 13` в фоне →
`input tap` → `pull` → `show_touches 0`. `--time-limit` — потолок, а не длина;
таймбейс переменный, поэтому в ffmpeg обязательно `-r 30 -fps_mode cfr`.
Статусбар с часами и адресную строку Chrome (в ней локальный IP) срезать
кропом: для 1344×2992 это `crop=1344:2528:0:330`. Тему панели телефон помнит
свою — переключить на тёмную перед записью и вернуть после.

## Фоны из нейросети и шрифты

Фон первого экрана и OG-баннера — чертёж домашней сети — сгенерирован через MCP
`neuropix` (модель `nano-banana`, 16-9, 2k, ~4 кредита). Генерировать можно
только атмосферу и фактуры; **ничего, что можно принять за экран панели** —
продуктовые кадры только настоящие. Сырьё в `gen-src/` (gitignored: ссылка на
результат живёт 7 суток, скачивать сразу), `node landing/pack-gen.cjs` пережимает в
`gen/` (1920 и 960 px + 48-px постер). Грабли: `model` передавать явно; из
Windows-сессии пути референсов — `/mnt/c/...`, сервер живёт в WSL; неудачная
генерация всё равно может списать кредиты. Логотип бренда на нарисованном
роутере заретуширован `sharp` (патч соседнего пластика поверх надписи).

Шрифты лежат рядом, страница к Google не ходит: `node landing/fonts/fetch.cjs`
скачивает woff2 (cyrillic + latin) и пишет `fonts/fonts.css`. Commissioner —
вариативный, один файл на весь диапазон 400–800.

Параллакс — только на фоновых слоях (`data-parallax`, 8–12 % от прокрутки),
кадры и ролики не двигаются; при `prefers-reduced-motion` он не запускается.

### Что именно обезличивается

`shoot/anonmap.py` строит карту подстановок по выгруженным ответам и заменяет:

- **имена и id профилей** — на «город, страна» с тем же флагом (флаг важен:
  панель фильтрует по стране именно по нему);
- **названия групп, подписок и цепочек** — на нейтральные (`Example VPN` и т. п.);
- **серверы, SNI, ключи, пароли, uuid** — на `srv-NN.example-vpn.net` и маски;
- **адреса подписок** — хост и токен целиком; в токенах встречается base64 с
  почтой и логином внутри, поэтому маскируется любая длинная буквенно-цифровая
  последовательность;
- **публичные IP** — на диапазон `203.0.113.0/24` (RFC 5737), приватные не трогаются;
- **личные домены и почту** — на `example.com` / `you@example.com`;
- **имя пользователя панели** — на `admin`.

Обратная подстановка тоже есть: подставные id прокси переводит обратно в
настоящие, когда панель запрашивает конкретный профиль, — иначе шторки и
действия перестали бы работать.

Проверить, что ничего не осталось:

```sh
cd landing/shoot && python3 verify.py
```

Скрипт прогоняет выгрузки через ту же карту и ищет остатки: настоящие публичные
адреса, длинные токены и ключи карты, которые почему-то не заменились. Пустой
список — то, что нужно.

### Мелочи, на которые уходит время

- **Флаги стран.** Windows не рисует региональные индикаторы вообще — вместо
  флага видны две буквы. `shots.cjs` подмешивает Noto Color Emoji, но **только**
  на диапазон `U+1F1E6–1F1FF`: без ограничения цифры уезжают в эмодзи-шрифт (в
  нём есть глифы клавиш-цифр), и «183 Мбит/с» рендерится враскоряку.
- **Раскрытие секций.** Кликать надо по кнопке-заголовку; клик по текстовому
  узлу внутри неё раскрытия не даёт, и кадр выходит пустым — скрипт проверяет
  высоту документа и ругается, если секция не раскрылась.
- **Прелоадер панели.** Пока идёт запрос, оверлей перекрывает страницу, поэтому
  клики идут с `force: true`.
- **Версия.** На роутере обычно стоит предыдущий релиз, а dev-сборка — уже новый;
  карта подменяет номер версии, чтобы кадры не противоречили тексту сайта.

Конвертеры `pack.cjs` и `pack-gen.cjs` берут `sharp` из `panel/node_modules` —
отдельный пакет ставить не нужно.
